# 사내 장비 예약 서비스 기획서

## 1. 배경과 목표

- 현재는 장비 대여를 메신저와 엑셀로 관리한다. [p.1]
- 목표는 장비 예약과 대여 현황을 한 화면에서 관리하는 것이다. [p.1]
- 1차 출시 범위는 사내 임직원용 웹 화면과 운영자 관리 화면이다. [p.1]

## 2. 사용자와 역할

- 임직원은 장비를 검색하고 예약할 수 있다. [p.2]
- 운영자는 장비를 등록하고 대여 상태를 변경할 수 있다. [p.2]
- 예약을 승인하는 승인자 역할이 있다. 승인자는 운영자와 같은 사람일 수 있다. [p.2]
- 관리자는 전체 예약 내역을 조회한다. [p.2]

## 3. 주요 용어

- 장비: 임직원이 예약해서 사용하는 물품이다. 노트북, 프로젝터, 카메라가 있다. [p.2]
- 자산: 장비와 같은 뜻으로 사용한다. [p.2]
- 예약: 장비를 특정 기간 사용하겠다고 신청하는 것이다. [p.2]
- 대여: 예약한 장비를 실제로 수령해 사용하는 상태를 뜻한다. 문서에 따라 예약과 같은 뜻으로도 쓴다. [p.2]
- 승인: 예약을 확정하기 전에 승인자가 검토하는 절차다. [p.2]
- 반납: 대여한 장비를 운영자에게 돌려주는 것이다. [p.3]
- 연체: 반납 예정일을 넘긴 상태다. [p.3]

## 4. 예약 프로세스

1. 임직원이 장비 목록에서 원하는 장비와 기간을 선택한다. [p.3]
2. 시스템이 해당 기간의 재고를 확인한다. [p.3]
3. 재고가 있으면 예약 신청을 생성하고 승인자에게 알린다. [p.3]
4. 승인자는 예약 내용을 확인해 승인하거나 반려한다. [p.3]
5. 승인되면 임직원에게 확정 알림을 보낸다. [p.3]
6. 임직원은 운영자에게서 장비를 수령한다. [p.3]
7. 반납은 운영자가 처리한다. [p.3]

- 재고가 없으면 대기 예약을 만들 수 있다. [p.3]
- 같은 장비에 중복 예약이 생기면 먼저 신청한 예약을 우선한다. [p.3]
- 예약 취소 정책은 아직 정하지 않았다. [p.3]

## 5. 화면

- 장비 목록: 이름, 분류, 상태, 다음 가능한 기간을 보여 준다. [p.4]
- 예약 화면: 기간, 수량, 사용 목적을 입력한다. [p.4]
- 운영자 화면: 예약 승인, 대여 처리, 반납 처리를 한 화면에서 한다. [p.4]
- 외부 캘린더와 연동해 예약 일정을 보여 줄 예정이다. 연동 실패 시 동작은 정하지 않았다. [p.4]

## 6. 데이터

- 예약은 예약 ID, 장비 ID, 사용자 ID, 시작일, 종료일, 상태, 승인자 ID를 가진다. [p.5]
- 장비는 장비 ID, 이름, 분류, 상태, 소유 부서를 가진다. [p.5]
- 예약 상태는 신청, 승인, 반려, 대여, 반납으로 한다. [p.5]
- 상태 변경 이력은 저장한다. [p.5]
- 예약 데이터 보존 기간은 정하지 않았다. [p.5]

## 7. 미정 사항

- 승인 SLA와 승인 거절 사유 코드 [p.5]
- 반납 지연 시 알림과 제재 정책 [p.5]
- 예약 취소, 변경, 노쇼 정책 [p.5]
- 외부 캘린더 연동 실패 시 대체 동작 [p.5]

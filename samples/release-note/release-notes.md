# SampleApp 2.0.0 릴리스 노트

2026-10-27 · 대상: 앱 사용자

**더 빠르고 안전해진 SampleApp 2.0**

검색과 시작 속도를 개선하고 미리보기 보안을 강화했습니다. 레거시 내보내기 기능은 종료되므로 업그레이드 전 확인해 주세요.

## 업그레이드 전 확인

### 레거시 내보내기 기능 종료

2.0.0부터 예전 '내보내기(legacy)' 메뉴를 제공하지 않습니다. 새 내보내기 메뉴를 이용해 주세요.

- 조치: 설정 > 데이터 > 내보내기에서 새 형식으로 내보낸 뒤, 기존 자동화가 있다면 새 API로 교체하세요.
- [자세히 보기](<https://example.com/help/export>)

## 한눈에 보기

- **오타에도 강한 검색** — 비슷한 단어와 띄어쓰기가 달라도 원하는 항목을 찾습니다.
- **더 빠른 시작** — 앱을 열고 첫 화면이 보이기까지 걸리는 시간을 줄였습니다.
- **안전한 미리보기** — 링크 미리보기에서 발생할 수 있던 스크립트 실행 문제를 수정했습니다.

## 새 기능

### 오타에도 강한 검색

검색어에 오타가 있거나 띄어쓰기가 달라도 비슷한 결과를 찾아 줍니다.

- 사용 방법: 검색창에 평소 쓰던 단어를 그대로 입력해 보세요.
- [자세히 보기](<https://example.com/help/search>)

## 개선

### 앱 시작 속도 개선

앱을 열고 첫 화면이 보이기까지 걸리는 시간을 줄였습니다.

- 사용 방법: 앱을 다시 실행하면 적용됩니다.

## 수정

### 로그인이 풀리던 문제

인증 토큰이 만료된 뒤에도 로그인 상태가 유지되지 않던 문제를 고쳤습니다.

- 사용 방법: 앱을 다시 실행하면 적용됩니다.

## 보안

### 미리보기 화면 보안 강화

링크 미리보기에서 발생할 수 있던 스크립트 실행 문제를 수정했습니다. 추가로 하실 일은 없습니다.

## 업그레이드 참고

- 2.0.0은 이전 버전의 레거시 내보내기 파일을 읽지 않습니다.
- 자동화에서 레거시 내보내기 API를 사용하고 있다면 새 API로 교체해야 합니다.

## 알려진 문제

- 일부 Android 기기에서 첫 실행 후 홈 위젯이 늦게 갱신될 수 있습니다. 다음 업데이트에서 개선할 예정입니다.
